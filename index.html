Como Jogar

CONTROLO

Mover a Garra

Usa as setas do teclado ou WASD para posicionar a garra sobre as cápsulas.

Usa o joystick para posicionar a garra sobre as cápsulas.

AÇÃO

Apanhar

Prime ESPAÇO para descer a garra e tentar apanhar uma cápsula.

Carrega no botão IR para descer a garra e tentar apanhar uma cápsula.

ABRIR

Abrir Cápsula

Clica na cápsula que saiu para a abrir e descobrir o prémio lá dentro!

Toca na cápsula que saiu para a abrir e descobrir o prémio lá dentro!

PREMIOS

Coleção

Muda para a vista COLEÇÃO para veres os prémios desbloqueados. Clica neles para os inspecionar!

Muda para a vista COLEÇÃO para veres os prémios desbloqueados. Toca neles para os inspecionar!

PAUSA

Mesa

Vai até à vista MESA para uma pausa relaxante no ambiente do arcade.

OPÇÕES

Configurações

Usa o painel Configurações (canto superior direito) para mudar a dificuldade, tema e volume.
